# WristMotion — حرکت، روی مچ

یه بازسازی از صفحهٔ اپل واچ SE ۳ که فارسی رو از اول جدی می‌گیره: متن خودمونی، فونت پینار، چیدمان راست‌به‌چپ و انیمیشنی که با متن فارسی تداخل نداره.

نمونه‌کار [سجاد دهقان](https://github.com/sajjad-dehghan) در بازسازی رابط، بومی‌سازی و اجرای جزئیات بصری. [English README](../README.md)

## سهم من در این پروژه

- بازسازی هیرو با پنج اپل واچ؛ از نسبت‌ها و فاصله‌ها تا تیتر گرادیانی، دکمهٔ خرید و کنترل پخش.
- ترجمه و بررسی ۶۱۸ عبارت یا نام تجاری؛ شامل متن، منو، توضیح تصویر و برچسب‌های دسترس‌پذیری.
- اضافه کردن فارسی پیش‌فرض، انگلیسی، پینار در چهار وزن و اعداد فارسی.
- اصلاح جهت‌ها؛ کابل از راست وارد می‌شه، ولی صفحهٔ ساعت وارونه نمی‌شه.
- بررسی واقعی در مرورگر و اصلاح لایه‌های تصویر در موبایل.

تصاویر، ویدئو و اجزای تعاملی اصلی از Apple حفظ و سازگار شده‌اند. کار من روی بازسازی، بومی‌سازی، هیروی سفارشی و یکپارچه‌سازی متمرکز است؛ تولید دارایی‌های اصلی محصول به نام من ثبت نشده.

## امکانات

- ویدئوی هیرو با پخش و توقف، رسانهٔ مناسب اندازهٔ صفحه و پشتیبانی از کاهش حرکت.
- جابه‌جایی فارسی و انگلیسی با حفظ پارامترها و موقعیت بخش‌ها.
- گالری ویژگی‌ها، جزئیات محصول و انتخاب رنگ بدنه.
- اجرای محلی بدون نصب وابستگی یا مرحلهٔ ساخت فرانت‌اند.

## اجرا

Node.js نسخهٔ ۲۰ یا بالاتر:

```bash
git clone https://github.com/sajjad-dehghan/wrist-motion.git
cd wrist-motion
npm run dev
```

آدرس پیش‌نمایش: **http://127.0.0.1:4173/**. فارسی در `/` و انگلیسی در `/en/` است. برای مقایسهٔ ثابت هیرو، `/?reference=1` را باز کن.

برای بررسی فایل‌ها و رسانه‌ها، `npm run check` را اجرا کن. [جزئیات بررسی](../QA.md) و [منابع](../SOURCES.md) ثبت شده‌اند.

## نکتهٔ مرجع

تصویر Refero فقط ابتدای صفحهٔ دسکتاپ را نشان می‌دهد. بخش‌های پایین از صفحهٔ رسمی زمان پیاده‌سازی گرفته شده‌اند؛ تطبیق تاریخی تمام صفحه ادعا نمی‌شود.

دارایی‌ها و نشان‌های Apple متعلق به صاحبانشان هستند. این پروژه نمونه‌کار مستقل است و وابسته به Apple نیست. لینک‌های خرید و حساب به سایت رسمی Apple می‌روند.

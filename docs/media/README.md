# README media

The opening GIF is derived from `dist/assets/hero-large_2x.mp4`, Apple's retained five-watch film. It is a looping 900-pixel-wide, 12 fps preview; the website itself uses MP4 media. The GIF is embedded as a repository-relative image, following [GitHub's README image guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes#relative-links-and-image-paths-in-markdown-files).

`wordmark.svg` is the project-specific WristMotion presentation graphic. JPEG screenshots show the actual locally rendered implementation, not generated interface mockups.

Hero screenshots use `?reference=1`, which pauses the film at the review frame. The normal website plays the animation. Apple retains ownership of the product imagery and film; see the repository source attribution.
